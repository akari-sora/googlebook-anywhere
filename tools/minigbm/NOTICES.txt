Third-Party Source & License Notices for the amd-hx370 libminigbm_gralloc.so
=============================================================================

The amd-hx370 image installs one rebuilt library at
/vendor/lib64/libminigbm_gralloc.so. Both the safe entry and the native
entry load that file. builder/vendor.sh copies this notices file to
/vendor/etc/NOTICES-amd-hx370-minigbm.txt when [gralloc] is set.

The library is built by tools/minigbm/build-libminigbm-gralloc.sh from:

  - AOSP platform/external/minigbm
    commit ce79bbee67b3e2ea7abb110e1415e9ceceaa6471
    tree   95c2eb6837a39a6ef62ae454c5d9767cf2066c53
  - tools/minigbm/upstream-delta.patch, the upstream changes c662136
    (drop VIRTGPU_PARAM_GUEST_VRAM / RESOURCE_SYNC), 9d21b5c
    (drv_is_protected_usage_permitted), and 0c4f081 (nvl_ids, Intel
    NVL-S/NVL-P PCI ids, not AMD Navi), applied on that commit
  - tools/minigbm/amdgpu_linear.c (Copyright 2026 ImL1s, plus the
    Chromium OS Authors copyright on the parts copied from minigbm)
  - libdrm 2.4.123 headers. The library links the image's libdrm.so;
    it does not embed libdrm.
    sha256 a2b98567a149a74b0f50e91e825f9c0315d86e7be9b74394dae8b298caadb79e
